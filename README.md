UX/UI Design — Online City Tours

Цель: разработать концепцию сервиса для самостоятельных онлайн-экскурсий по городу, который помогает пользователю выбрать готовый маршрут или подобрать прогулку по интересам.

Моя роль: разработка идеи продукта, пользовательского сценария, структуры интерфейса и прототипирование основных экранов сервиса.

Инструменты: Balsamiq Wireframes, UX/UI-проектирование, User Flow, прототипирование интерфейсов.

Результат: создан прототип сервиса городских экскурсий: выбор города, подбор маршрутов по категориям, AI-маршрут, просмотр продолжительности и точек прогулки, карта маршрута и возможность использовать аудиогид во время экскурсии.
